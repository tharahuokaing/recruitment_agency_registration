A responsive, multi-role **Account Registration Portal** built for **Huokaing Thara Recruitment Agency (ភ្នាក់ងារជ្រើសរើសពលករ ហួកាំងថារ៉ា)**. Enables both job seekers and enterprise clients to register accounts, complete profile data validation, and seamlessly transition into the login portal.
## 🚀 Live Demo

🔗 **Live Deployment:** [Huokaing Thara Registration Portal](https://tharahuokaing.github.io/recruitment_agency_register/)

## ✨ Key Features

- **🌐 Dual Language Support (Khmer & English):** Instant bilingual interface toggling using `data-km` and `data-en` attributes.
- **👥 Multi-Role Account Support:** Selectable account types for Candidates (Job Seekers) and Employers (Enterprises).
- **🔒 Password Verification & Masking:** Real-time password confirmation check and independent show/hide toggles for both password fields.
- **🚀 Automatic Login Redirection:** Upon completing registration, users are automatically routed to the [Login Portal](https://tharahuokaing.github.io/recruitment_agency_login/).
- **📱 Responsive UI Layout:** Dark theme (`#0a0e1a`) with gold accents (`#d4af37`), designed for mobile devices, tablets, and desktops using Google Fonts (*Kantumruy Pro* & *Inter*).
